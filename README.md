# neiromaster

RAG-ассистент по внутренним регламентам предприятия. Сотрудник задаёт вопрос по
документам компании и получает ответ строго по фрагментам загруженных документов со
ссылкой на смысл источника. Вопрос без ответа не теряется — уходит в очередь
администратору, ответ приходит в личный кабинет сотрудника.

Это «ядро» проекта: разбиение документов на части (чанкинг) + смысловая
классификация по папкам + ответ пользователю (RAG) + система логина и ролей.
Конструктор планов адаптации, этапы/подэтапы, рассылка и хеш-дедупликация документов
из этой сборки убраны.

## Возможности
- Загрузка документов (PDF/DOCX/PPTX/HTML) → смысловое описание → чанкинг с
  перекрытием → эмбеддинги → Qdrant.
- Смысловые папки — логические категории, которыми управляет человек; ИИ только
  относит документы и чанки в существующие папки (мульти-лейбл).
- Векторный поиск + реранк + генерация ответа строго по фрагментам документов.
- Память диалога; классификация вопроса `rag`/`general`/`escalate` (детект ЧС).
- Эскалация: вопрос без ответа → очередь администратору → ответ в кабинет сотрудника.
- Аккаунты и роли (владелец/админ/сотрудник) на PostgreSQL, самостоятельная регистрация.

## Стек
- Python + FastAPI + uvicorn
- PostgreSQL (аккаунты, сессии, смысловые папки) — `psycopg`
- Qdrant (чанки регламентов, векторы папок, описания документов)
- Ollama (генерация/классификация), эмбеддинги bge-m3 (1024d)
- docling (разбор документов)
- Фронтенд: статические HTML (`static/`)

## Точки входа
- `app.py` — FastAPI: страницы, `/ask`, документы, папки, пользователи, эскалации.
- `rag.py` — ядро RAG-пайплайна (классификация вопроса, каскадный поиск, генерация).
- `indexing.py` — конвейер документа: docling → чанкинг → эмбеддинги → Qdrant.
- `classify.py` — смысловое описание документов и отнесение к папкам.
- `index_documents.py` — CLI пакетной индексации `data/documents/`.
- `seed_knowledge.py` — ручной посев смысловых папок из `data/knowledge_seed.json`.

## Запуск локально
Нужны запущенные PostgreSQL, Qdrant и Ollama (см. переменные окружения в `config.py`
и `db.py`).

```bash
python -m venv .venv && source .venv/bin/activate   # или .venv\Scripts\activate на Windows
pip install -r requirements.txt
python seed_knowledge.py            # засеять смысловые папки (при пустой БД)
python index_documents.py           # разовая индексация data/documents (опционально)
uvicorn app:app --port 8000
```

При первом старте создаётся учётная запись главного администратора — логин и пароль
печатаются в консоль (и дублируются в файл, путь укажет `users.INITIAL_CREDENTIALS_PATH`).

## Переменные окружения (основные)
- `NEIROMASTER_DB_DSN` — строка подключения к PostgreSQL (по умолчанию локальная).
- `NEIROMASTER_PII_KEY` — ключ Fernet для шифрования ПДн в БД (опционально).
- Хосты Qdrant/Ollama и модели — в `config.py`.

## Тесты
Часть тестов работает без внешних сервисов (подменяют тяжёлые зависимости заглушками):

