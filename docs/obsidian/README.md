# neiromaster

## Что это
RAG-ассистент по внутренним регламентам предприятия + конструктор планов адаптации
новых сотрудников. Сотрудник задаёт вопросы по документам компании и получает ответ
со ссылкой на источник; администратор собирает поэтапный план адаптации, система сама
пишет тексты сообщений по загруженным документам.

## Функции / возможности
- Загрузка документов (PDF/DOCX/PPTX/HTML) → фоновая очередь → авто-классификация по темам
- Посекционный чанкинг (по заголовкам docling или номерам пунктов) + payload-индексы Qdrant
- Векторный поиск + реранк + генерация ответа строго по фрагментам документов
- Память диалога: обрывочный вопрос дописывается по истории до самостоятельного
- Классификация вопроса на `rag` / `general` / `escalate` (детект ЧС — risk_flag)
- Вопрос без ответа (ЧС или не нашлось в базе) → очередь администратору, ответ в кабинет сотрудника
- Аккаунты и роли: владелец → админы → сотрудники, самостоятельная регистрация
- Личная карточка сотрудника: ФИО, должность, отдел, наставник, руководитель, план
- Конструктор плана адаптации: этапы/подэтапы из каталога + свои, привязка к должности
- Авто-генерация текстов сообщений по плану + перегенерация одного подэтапа
- Персональное расписание сотрудника: пересчёт на дату выхода + подстановка плейсхолдеров
- Экспорт плана/расписания в plan.json/md, schedule.json/md

## Стек технологий
- Язык: Python
- Веб: FastAPI + uvicorn
- БД аккаунтов: PostgreSQL (psycopg + пул), схема в `db.py`
- Векторная БД: Qdrant (коллекции документов и тем)
- LLM: Ollama (qwen3:14b — генерация, qwen2.5:3b — классификация)
- Разбор документов: docling (структура, таблицы, чанкинг)
- Эмбеддинги: bge-m3 (1024d)
- Хранение метаданных: JSON-файлы в `data/` (БД пока нет)

## Как запустить локально
```
source .venv/bin/activate
python index_documents.py     # разовая индексация data/documents
uvicorn app:app --port 8000   # или systemd-сервис rag-app
```

## Точки входа
- `app.py` — FastAPI: страницы, /ask, документы, планы, пользователи
- `index_documents.py` — CLI разовой пакетной индексации
- `install.sh` — установка на Linux-сервер (venv, Qdrant, Ollama, systemd)

## Статус против плана адаптации (docx)
- Готово: база знаний+ответы, доступ/роли, конструктор плана, авто-тексты, личные расписания
- Частично: экспорт есть, но БД нет (план требует); приложение — только веб-кабинет
- Нет: служба авто-рассылки по расписанию, транскрибация аудио/видео, прогресс по этапам
- Готово (доделано): маршрутизация эскалации/вопроса-без-ответа человеку (`questions.py`)
